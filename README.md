# homebrew-tap

Homebrew formulae for [aviral2552](https://github.com/aviral2552)'s tools.

```bash
brew tap aviral2552/tap
brew trust aviral2552/tap   # Homebrew's confirmation for third-party taps
brew install aviral2552/tap/scrubmac
```

| Formula | Description |
|---|---|
| [scrubmac](https://github.com/aviral2552/scrubmac) | Update and clean your dev tools with one command |
